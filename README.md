# Курсовая работа: распознавание и синонимическое обезличивание ПДн

Вариант 20 (чётный набор атрибутов). Программа распознаёт персональные данные
в русскоязычном тексте, проверяет контрольные разряды структурированных
реквизитов и выполняет синонимическое обезличивание с сохранением морфологии,
формата, косвенных признаков и идемпотентности.

## Обязательные атрибуты

`SURNAME`, `NAME`, `INN`, `PASSPORT`, `BANK_CARD`, `OGRNIP`, `IP`, `EMAIL`,
`BIRTH_CERT`, `KLADR`.

Дополнительно поддерживаются `PATRONYMIC`, `PHONE`, `SNILS` — они уже были
реализованы в ЛР №1/№2 и позволяют показать морфологию и контрольные разряды.
Итого 13 атрибутов.

## Установка

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Модель `models/rubert_ner` — символическая ссылка на
`../rubert_ner_factrueval_augmented_best`. Модель не переобучается: она
обучена на factRuEval2016 с синтетическими ФИО в ЛР №1 и переиспользуется.

## Запуск программы

```bash
# текст аргументом
python main.py --text "Иван Петров, ИНН 7707083893, телефон +7 (999) 123-45-67."

# файл
python main.py --file input.txt

# только правила, без загрузки RuBERT
python main.py --no-model --text "ИНН 7707083893"

# полный JSON с картой замен
python main.py --json --text "Иван Петров, ИНН 7707083893"
```

Пример вывода:

```
Лев Тихомиров, ИНН 7707998788, телефон +7 (999) 130-52-61.

Атрибуты: [["NAME", 0, 4], ["SURNAME", 5, 11], ["INN", 17, 27], ["PHONE", 37, 55]]
```

## Набор данных

- `train.jsonl` — 6122 документа: factRuEval2016 train + синтетические ФИО;
- `val.jsonl` — 132 документа;
- `test.jsonl` — 180 комплексных документов, в каждом все 13 атрибутов
  (2340 размеченных упоминаний);
- `negative.jsonl` — 60 документов без ПДн (негативные примеры);
- `hard.jsonl` — 90 документов с другими формулировками и форматами записи
  (паспорт без пробелов, карта через пробелы/дефисы, ИНН/СНИЛС/КЛАДР с
  разделителями, телефон `8-999-…`);
- `data/test_by_attribute/*.jsonl` — по 60 документов на каждый атрибут.

Разметка — BIO. Один токен относится только к одному атрибуту.

## BERTScore

Модель `DeepPavlov/rubert-base-cased`, слой 9, 180 документов:

| Вариант | Precision | Recall | F1 |
|---|---:|---:|---:|
| Синонимическое обезличивание | 0.9210 | 0.9259 | **0.9235** |
| Маскирование только ПДн | 0.4871 | 0.5484 | **0.5159** |
| Маскирование всего текста | 0.3290 | 0.2970 | **0.3122** |

Синонимическая замена сохраняет смысл существенно лучше маскирования:
BERTScore F1 0.924 против 0.516 и 0.312. Причина — замена сохраняет длину,
морфологию, синтаксические связи и структуру реквизитов, тогда как маска
разрушает контекст.

## Решённые проблемы

1. **Род имён типа Женя/Саша.** Род определяется по соседнему слову
   (глагол прошедшего времени, прилагательное, роль: «сотрудник» /
   «сотрудница»), а не по окончанию имени. Реализовано в
   `_context_gender` (`src/anonymize.py`).
2. **Фамилия Иванова.** Для фамилий на `-ова/-ева/-ина` род берётся из
   контекста и согласуется с именем и отчеством; падеж сохраняется.
3. **Двойные фамилии.** `Иванов-Петров` заменяется на двойную фамилию с
   сохранением дефиса и склонения обеих частей.

## BERTScore и transformers 5.x

`bert-score` 0.3.13 несовместим с `transformers` 5.x: при
`max_length=tokenizer.model_max_length` возникает `OverflowError`. В
`scripts/evaluate_bertscore.py` применён минимальный monkeypatch
`bert_score.utils.sent_encode` с явным `max_length=512, truncation=True`.
